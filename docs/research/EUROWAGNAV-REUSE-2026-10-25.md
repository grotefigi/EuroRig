The country builder generates an evidence-coverage report using `tools/audit_restriction_coverage.py`; its ADR classification diagnostic was added after reproducing the narrow current classifier result described above. The 51-test Python suite passes. Authority-source ingestion, matching, freshness and update automation remain work to implement; the audit alone does not add missing restrictions.
