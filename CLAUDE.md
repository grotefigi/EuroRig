# EuroRig project handover

Read [the current handover](docs/HANDOVER-CLAUDE-2026-10-27.md), [the roadmap](ROADMAP.md), and [the progress ledger](docs/planning/progress/codex.json) before changing the project. Treat historical planning documents as dated records.

Use the approved native interface and original EuroRig code. Preserve private device data, reference material, map packages, credentials and local receipts outside Git. Do not claim that a route is legally safe, a country is fully covered, or a release is ready without the required evidence. Keep changes focused, preserve uncommitted work, and run checks appropriate to the changed behavior.

The owner wants one roadmap package at a time. If 40 minutes pass without significant progress, record the obstacle and proceed to the next package; unresolved dependencies still prevent acceptance.
