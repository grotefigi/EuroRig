EuroRig's cartographic style is original EuroRig code. Map detail is imported
from a separate offline OpenMapTiles vector file; it is not bundled in the APK.
Buildings and boundaries use recorded geometry. Heights are approximate display
heights from the tile data, with a default extrusion where no height is supplied.
These visual layers are not truck restriction evidence.
